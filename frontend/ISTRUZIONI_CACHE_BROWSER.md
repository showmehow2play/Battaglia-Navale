# 🧹 Come Svuotare la Cache per Browser

## 🍎 Safari (Mac)

### Metodo 1 - Menu Sviluppo (Consigliato)
1. Abilita il menu Sviluppo: Safari → Preferenze → Avanzate → Spunta "Mostra menu Sviluppo"
2. Menu Sviluppo → Svuota cache (o premi `Cmd+Option+E`)
3. Chiudi tutte le schede del gioco
4. Riapri il gioco

### Metodo 2 - Cancella Cronologia
1. Safari → Cancella cronologia...
2. Seleziona "tutta la cronologia"
3. Clicca "Cancella cronologia"
4. Riapri il gioco

### Metodo 3 - Modalità Privata
1. File → Nuova finestra privata (o `Cmd+Shift+N`)
2. Apri il gioco nella finestra privata
3. Testa la funzionalità

---

## 🦊 Firefox

### Metodo 1 - Ricarica Forzata (Più Veloce)
1. Apri il gioco
2. Premi `Ctrl+Shift+R` (Windows/Linux) o `Cmd+Shift+R` (Mac)
3. Questo forza il ricaricamento ignorando la cache

### Metodo 2 - Cancella Cache Completa
1. Premi `Ctrl+Shift+Delete` (Windows/Linux) o `Cmd+Shift+Delete` (Mac)
2. Seleziona "Cache"
3. Intervallo di tempo: "Tutto"
4. Clicca "Cancella adesso"
5. Chiudi tutte le schede del gioco
6. Riapri il gioco

### Metodo 3 - Modalità Navigazione Anonima
1. File → Nuova finestra anonima (o `Ctrl+Shift+P` / `Cmd+Shift+P`)
2. Apri il gioco nella finestra anonima
3. Testa la funzionalità

---

## 🔧 Metodo Universale - Disabilita Cache (Per Sviluppo)

### Safari
1. Menu Sviluppo → Disabilita cache
2. Mantieni aperto il menu Sviluppo mentre lavori

### Firefox
1. Apri Strumenti di sviluppo (F12)
2. Vai su Impostazioni (icona ingranaggio)
3. Spunta "Disabilita cache HTTP (quando la casella degli strumenti è aperta)"
4. Mantieni aperti gli strumenti di sviluppo mentre lavori

### Chrome
1. Apri DevTools (F12)
2. Vai su Network
3. Spunta "Disable cache"
4. Mantieni aperti i DevTools mentre lavori

---

## ✅ Come Verificare che Funzioni

Dopo aver svuotato la cache:

1. Apri il gioco
2. Apri la Console del browser (F12 → Console)
3. Non dovrebbero esserci errori in rosso
4. Clicca su "Crea Partita Live"
5. Dovrebbe apparire il codice stanza

Se ancora non funziona, controlla la Console per errori specifici.

---

## 🚨 Se Ancora Non Funziona

1. Chiudi COMPLETAMENTE il browser (non solo la scheda)
2. Riapri il browser
3. Apri il gioco
4. Prova di nuovo

Oppure usa la modalità privata/anonima che garantisce sempre file freschi.
