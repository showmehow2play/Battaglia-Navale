🧹 Svuota Cache e Ricarica

📋 Istruzioni Manuali

Per Chrome/Edge:

  1. Premi Ctrl + Shift + Delete (Windows) o Cmd + Shift + Delete (Mac)
  2. Seleziona "Immagini e file memorizzati nella cache"
  3. Clicca "Cancella dati"
  4. Ricarica la pagina con Ctrl + F5 o Cmd + Shift + R

Per Firefox:

  1. Premi Ctrl + Shift + Delete (Windows) o Cmd + Shift + Delete (Mac)
  2. Seleziona "Cache"
  3. Clicca "Cancella adesso"
  4. Ricarica la pagina con Ctrl + F5 o Cmd + Shift + R

🔄 Ricarica Forzata

Dopo aver svuotato la cache, usa uno di questi metodi per ricaricare:

  • Windows: Ctrl + F5 o Ctrl + Shift + R
  • Mac: Cmd + Shift + R
✅ Cache svuotata! La pagina verrà ricaricata tra 2 secondi...

⚠️ Nota Importante

Dopo aver svuotato la cache e ricaricato:

  • Apri la Console del browser (F12 → Console)
  • Avvia una partita multiplayer
  • Quando affondi una nave, dovresti vedere i log nella console
  • Se ancora non vedi i log, prova a chiudere completamente il browser e riaprirlo
