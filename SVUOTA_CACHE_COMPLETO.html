🔄 Svuota Cache Completo

📋 Metodo 1: Ricarica Forzata (CONSIGLIATO)

Mac:

Cmd + Shift + R

Windows/Linux:

Ctrl + Shift + R

Oppure:

Ctrl + F5

🔧 Metodo 2: Svuota Cache Manualmente

Chrome/Edge:

  1. Premi Ctrl + Shift + Delete (o Cmd + Shift + Delete su Mac)
  2. Seleziona "Immagini e file memorizzati nella cache"
  3. Clicca "Cancella dati"

Firefox:

  1. Premi Ctrl + Shift + Delete
  2. Seleziona "Cache"
  3. Clicca "Cancella adesso"

Safari:

  1. Menu Safari → Preferenze → Avanzate
  2. Abilita "Mostra menu Sviluppo"
  3. Menu Sviluppo → Svuota cache

🕵️ Metodo 3: Modalità Privata/Incognito

Chrome/Edge: Ctrl + Shift + N

Firefox: Ctrl + Shift + P

Safari: Cmd + Shift + N

Poi apri: index.html

🛠️ Metodo 4: Disabilita Cache (DevTools)

  1. Apri DevTools: F12
  2. Vai alla tab "Network"
  3. Spunta "Disable cache"
  4. Ricarica la pagina

✅ Verifica che il Layout sia Corretto

Dopo aver svuotato la cache, verifica che:

  • ✅ Griglia nemica sia a sinistra
  • ✅ Griglia mia sia al centro
  • ✅ Chat sia a destra (350px di larghezza)
  • ✅ Input chat sia visibile e utilizzabile
  • ✅ Flotte siano sotto le rispettive griglie
